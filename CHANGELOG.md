# 1.1.0-beta.1

- Added draggable minimap icon with independent marker/pathing checkboxes.
- Added shared terrain/recorded-route guidance, map lines, waypoint distance and route-editor entry.
- Blue/dark-gray controls; missing terrain coverage is explicitly reported.
- Navigation remains optional; native flight markers work independently.

# 1.0.1 — 2026-11-18

- Added original winged-boot artwork for the addon-list icon and finder window header.
- Bundled a compact native TGA texture; no additional dependency.
- Flight discovery and map-marker behavior are unchanged.

# 1.0.0 — 2026-11-18

- First stable standalone release, following user testing in Forever.
- Large Alliance flight-point markers, optional neutral hubs, town/region search and coordinate directory.
- Marker sizes and labels, Show on map, and per-character discovery status where provided by the client.
- Uses native flight-node data with bounded background scanning.
- No additional addons or external programs required.

# 0.1.0-beta.1

- Initial standalone Alliance flight-master finder using native client taxi/map data.
- Large map pins, neutral-hub filter, region/town search, coordinates and character-specific discovery state.
- Shared standalone folder bundled with Tranquility; no duplicated guild-only copy or third-party dependency.
